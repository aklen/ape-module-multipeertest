# Ape.Module.MultiPeerTest

Config-driven multi-peer Scene replication checks for Ape. The module authors or
observes three marker entities; `Ape.Launcher` owns the process entry point.

In an [ape-skeleton](https://github.com/aklen/ape-skeleton) workspace this independent
Git checkout lives at `src/Ape.Modules/Ape.Module.MultiPeerTest/`. It retains the
history of the former MultiPeerTest example. No separate example executable is needed.

See [Docs/README.md](Docs/README.md) for sample configurations and integration tests.
