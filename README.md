# Ape.Example.MultiPeerTest

One author peer puts three objects in the scene and changes them on an interval. Further peers join over QUIC and only receive that scene.

In an [ape-skeleton](https://github.com/aklen/ape-skeleton) workspace this checkout is `src/Ape.Examples/Ape.Example.MultiPeerTest/`.
